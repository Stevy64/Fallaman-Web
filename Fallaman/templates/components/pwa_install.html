Installer Fallaman

Ajoutez l'application à votre écran d'accueil pour un accès plus rapide, même hors ligne.

Bientôt disponible

L'application mobile arrive bientôt sur les stores. En attendant, installez Fallaman sur votre écran d'accueil.

Installer l'application

  1. Appuyez sur Partager dans Safari.
  2. Choisissez Sur l'écran d'accueil.
  3. Validez avec Ajouter.
  1. Cliquez sur … en haut à droite d'Edge ou Chrome.
  2. Ouvrez Applications, puis Installer Fallaman.
  3. Vous pouvez aussi utiliser l'icône d'installation dans la barre d'adresse.
